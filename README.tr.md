# Windows Optimizer

Türkçe | [🇬🇧 English](README.md)

Windows 10/11 için modüler, açık kaynak bir optimizasyon aracı. Reklamları devre dışı bırakın, gereksiz özellikleri yönetin, RAM'i temizleyin ve arka plan süreçlerini tek tıkla kontrol edin.

## ✨ Özellikler

- **Reklam Engelleyici**: Başlat Menüsü, Dosya Gezgini, Kilit Ekranı ve Bildirim Merkezi'ndeki reklamları kaldırır.
- **Özellik Yöneticisi**: Bing Arama, Telemetri, Cortana ve tüketici özelliklerini açıp kapatır.
- **RAM Temizleyici**: Microsoft'un RAMMap aracını kullanarak bekleme belleğini temizler.
- **Arka Plan Yöneticisi**: Gereksiz arka plan uygulamalarını ve servislerini devre dışı bırakır.
