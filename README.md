# Windows Optimizer

[🇹🇷 Türkçe](README.tr.md) | English

A modular, open-source optimization tool for Windows 10/11. Disable ads, manage unnecessary features, clean RAM, and control background processes—all with a single click.

## ✨ Features

- **Ads Blocker**: Removes ads from Start Menu, File Explorer, Lock Screen, and Notification Center.
- **Feature Manager**: Toggle Bing Search, Telemetry, Cortana, and consumer features on/off.
- **RAM Cleaner**: Clears standby memory using Microsoft's RAMMap.
- **Background Manager**: Disables unnecessary background apps and services.
